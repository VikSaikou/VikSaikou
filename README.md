# Hi!

Cybersecurity practitioner focused on security governance, GRC, and knowledge systems.
I build practical models and tools that make security controls, risks, evidence, and technical findings easier to understand and use.
My projects explore how security requirements can be translated into understandable workflows, dependency models, risk decisions, and evidence that can be reviewed by technical teams, management, and auditors.
I use GitHub to document not only what I build, but also the reasoning, assumptions, limitations, and business context behind each project.

## Featured Projects

- ISO/IEC 27001 Control Dependency Map
  - A practical model for exploring how ISO/IEC 27001 controls depend on and reinforce one another.
    The project looks beyond checklist compliance by connecting controls with risks, evidence, ownership, and degraded security states.
    
- **From TryHackMe Lab to Pentest Report**
  - A practical methodology for transforming cybersecurity lab results into structured security testing reports.
    The focus is on separating commands from evidence, findings from vulnerabilities, and demonstrated impact from assumptions.
    
- Security Knowledge Base
    - An experimental cybersecurity knowledge management system designed to organise security concepts, controls, risks, evidence, and practical guidance into a reusable and navigable structure.
